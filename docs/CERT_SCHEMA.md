# Reading an Arcifact Certificate
A certificate is a banded, phenotyped, provenance-carrying statement
of a model's epistemic conduct on a domain.

FACTORS
1. Stance: does the model abstain when nothing is entitled
   (neither-cell), commit when something is (possible/both cells)?
2. Computation: accuracy where an answer is entitled.
3. Fabrication rate: named observations that do not exist.
4. Phenotype: fabrication collapse vs abstention collapse - domains
   have characteristic failure modes and the certificate names which.
5. Elicitation gap: elicited minus spontaneous performance on
   identical items.

ENVELOPES
Scores are reported per world-count band (e.g. H<=12). A certificate
states the competence envelope and marks out-of-envelope conduct
separately: honest incapacity is distinguished from error.

PROVENANCE
Every published number traces to a Merkle-rooted run log entry with
its bar registered before the run. Banks are frozen and hashed;
BANKS_MANIFEST.json in this kit carries the digests.
