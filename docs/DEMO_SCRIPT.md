# Ten-Minute Live Demonstration

Minute 0 to 2. Clone, verify integrity, show the CI badge: the
instrument proves itself before asking for trust.

Minute 2 to 5. Run their named model live: run_frontier.py on
evalw_numeric with a 25-item limit, then grade. Watch the
fabrication_rate field arrive. The number is theirs, produced on
their screen, against banks they can hash.

Minute 5 to 7. The governed row: same bank, 1.000 with
fabrication 0.000, provenance in BASELINES. State the mechanism
boundary plainly: how it is built is not public; what it does is
measured in front of you.

Minute 7 to 9. The agent result, spoken not shown: across 270
episodes on a corpus never seen in training, zero unwarranted
assertions, including statements about the agent's own actions.
For coding-agent hosts: the incident class where an agent
misreports what it did is the exact class the gate closes.

Minute 9 to 10. The pilot brief, the three-week shape, and one
question: which system, which release, which bars.
